    skills cheatsheet

    Every installed Claude Code skill in one line: what it does for you and when to type it.

    Type /<name> to run one, or just describe the task and Claude picks it. Skills from strangers run with full permissions — read a skill's SKILL.md before trusting it with secrets.

    #Use these for Say now

    • /grilling — get your plan attacked with hard questions until the weak spots show.
    • /the-fool — devil's advocate and pre-mortem: "how does this launch fail?"
    • /feature-forge — turn a fuzzy feature into user stories and acceptance criteria.
    • /tdd — build a feature test-first, red → green → refactor.
    • /diagnosing-bugs — a disciplined loop for bugs that won't die (e.g. the mic or the port issues).
    • /fastapi-expert — Say's backend: endpoints, Pydantic models, auth, async DB.
    • /javascript-pro — Say's MV3 extension code: async flows, workers, Fetch.
    • /cloudflare — DNS, Workers, and deploy for api.clible.com.
    • /secure-code-guardian — harden login, licences, and payment webhooks against OWASP Top 10.
    • /insecure-defaults — find unsafe defaults (debug on, open CORS, weak keys) before shipping.
    • /supply-chain-risk-auditor — check your npm/pip dependencies for risky packages.
    • /differential-review — security review of just what changed in a diff.
    • /second-opinion — get an independent second review of code or a decision.
    • /playwright-expert — write and fix Say's browser end-to-end tests.
    • /webapp-testing — drive a local web page with Playwright to check it really works.
    • /frontend-design — make the setup page and overlay look intentional, not templated.
    • /web-design-guidelines — audit UI for accessibility and UX mistakes.
    • /prompt-engineer — tune the AI fallback prompt so it only returns valid intents.

    #Thinking and planning

    • /plan — numbered plan, no code until you approve.
    • /planning — tracks multi-step, multi-session work in a file.
    • /prototype — throwaway build to answer one design question fast.
    • /research — look a question up in primary sources and save the findings as markdown.
    • /domain-modeling — agree on names for things; writes CONTEXT.md and decision records.
    • /codebase-design — design small interfaces that hide lots of logic; find where to split code.
    • /architecture-designer — system design, trade-offs, and decision records.
    • /spec-miner — pull a spec out of code nobody documented.
    • /doc-coauthoring — write a spec or proposal with Claude, step by step.

    #Vault rituals (this repo)

    • /idea — sharpen a rough thought into a pitch in ideas/.
    • /start — turn an idea into a project with brief, log, decisions, repo.
    • /log — end a session: log, decisions, lessons into the wiki.
    • /learn — save a source and fold what it teaches into the wiki.
    • /reflect — weekly cleanup of inbox, now.md, wiki, and rules.
    • /done — close a project and archive it.

    #Code quality and review

    • /code-review — find real bugs in the current diff (built in).
    • /review — security + performance + quality audit via a subagent.
    • /code-reviewer — broad PR review: bugs, smells, N+1 queries, naming.
    • /security-reviewer — security-focused review of code.
    • /security-review — security review of pending branch changes (built in).
    • /static-analysis — run Semgrep/CodeQL-style scanners and read the results.
    • /simplify — clean up changed code without hunting bugs.
    • /refactor — restructure with zero behavior change.
    • /debugging-wizard — trace an error from stack trace and logs to root cause.
    • /debug — straight-to-the-fix diagnosis.

    #Testing

    • /test-master — test plans, mocks, and coverage across a project.
    • /property-based-testing — generate many random inputs to break your parser or logic.

    #Languages

    • /python-pro — typed, tested modern Python.
    • /typescript-pro — strict TypeScript types and patterns.
    • /javascript-pro — modern JS and Node.
    • /golang-pro · /rust-engineer · /cpp-pro · /swift-expert · /kotlin-specialist · /csharp-developer · /php-pro · /sql-pro — expert help in that language.

    #Web frameworks

    • /react-expert — React 18/19 components, hooks, rendering bugs.
    • /vercel-react-best-practices — Vercel's React performance rules.
    • /vercel-composition-patterns — composing React components cleanly.
    • /vercel-react-view-transitions — smooth page-to-page animations.
    • /nextjs-developer — Next.js App Router, server components, SEO.
    • /shadcn — add and theme shadcn/ui components.
    • /migrate-radix-to-base — move a shadcn project from Radix to Base UI.
    • /vue-expert · /vue-expert-js · /angular-architect — Vue or Angular apps.
    • /django-expert · /django-storages-s3 · /rails-expert · /laravel-specialist · /nestjs-expert · /spring-boot-engineer · /java-architect · /dotnet-core-expert — backend in that framework.
    • /wordpress-pro · /shopify-expert · /salesforce-developer — work on that platform.

    #Mobile, games, hardware

    • /react-native-expert · /vercel-react-native-skills · /flutter-expert — mobile apps.
    • /game-developer — Unity/Unreal systems and performance.
    • /embedded-systems — microcontroller firmware.

    #APIs, data, AI

    • /api-designer — shape REST/GraphQL APIs and OpenAPI specs.
    • /graphql-architect — GraphQL schemas and resolvers.
    • /websocket-engineer — real-time connections.
    • /postgres-pro · /database-optimizer — slow queries, indexes, tuning.
    • /pandas-pro · /spark-engineer — data wrangling, small and huge.
    • /rag-architect — search-your-documents AI systems.
    • /fine-tuning-expert — train a model on your own data.
    • /ml-pipeline — training and model-release pipelines.
    • /mcp-builder · /mcp-developer — build tools Claude can call.
    • /claude-api — build on the Claude API correctly.

    #Ship and run

    • /deploy-to-vercel · /vercel-cli-with-tokens — push a site live on Vercel.
    • /vercel-optimize — cut Vercel cost and speed up a deployed site.
    • /docker-containerization — Dockerfiles and compose setups.
    • /devops-engineer — CI/CD, Docker, infra as code.
    • /kubernetes-specialist · /terraform-engineer · /cloud-architect · /microservices-architect — big-infra work; skip until you need it.
    • /monitoring-expert · /sre-engineer — logs, alerts, uptime targets.
    • /chaos-engineer — break things on purpose to test resilience.
    • /cli-developer — build command-line tools.
    • /legacy-modernizer — upgrade old code step by step.

    #Docs, design, and content

    • /code-documenter — docstrings, API docs, user guides.
    • /writing-guidelines — check prose against a style guide.
    • /writing-for-agents — write skills and agent instructions.
    • /skill-creator — make, test, and tune your own skills.
    • /canvas-design — posters and static art as PNG/PDF.
    • /algorithmic-art — generative art with p5.js.
    • /theme-factory — apply one of 10 color/font themes to a page or deck.
    • /brand-guidelines — Anthropic's look; only for Anthropic-styled work.
    • /web-artifacts-builder — richer multi-component HTML artifacts.
    • /ai-image-asset-generator — generate site images (needs a Gemini key).
    • /slack-gif-creator — animated GIFs for Slack.
    • /internal-comms — status updates and team announcements.
    • /docx · /pptx · /xlsx · /pdf — make or edit Office files and PDFs.

    #Housekeeping

    • /commit · /commit-pr — commit messages and PR descriptions.
    • /handoff · /compress · /budget-check — save state and watch token spend.
    • /wizard — a step-by-step script for things only you can click through.
    • /resolving-merge-conflicts — fix a stuck merge or rebase.
    • /atlassian-mcp — Jira and Confluence; skip unless you use them.
    • /template-skill — empty example; ignore.
