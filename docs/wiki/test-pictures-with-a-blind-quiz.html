    test pictures with a blind quiz

    To know if an AI-made picture actually holds an idea, show only the picture to a second model, quiz it, and redraw until it passes.

    • Write the questions and answer key from the source first. Then give the judge only the rendered image: no source, no captions. If it can't answer, a student looking at the picture can't either.
    • Grade the judge's answers in a separate call that does see the source and the key. Keep the misses: "Q3: the picture never shows where it happens" is exactly the redraw instruction.
    • Keep the best round, not the last. A redraw can make things worse.
    • Render to PNG before judging. Judging the SVG text lets labels leak through even when they're unreadable or overlapping in the real picture.
    • Cache the source as the first block of every source-side call. The map, draw and grade calls all reuse it.
    • This scores whether the picture carries the idea. It doesn't score whether people remember it. Only a human recall test does that.
    • The drawer will game the judge if it can. Shown the quiz questions, Gemini Flash-Lite added an "Answering Exam Qs" box listing all five answers, and the blind judge scored it 4/5. Give the drawer the facts that must be visible, never the questions, and reject pictures with numbered lists, "answer" boxes or pasted question text.
    • A quiz can't see layout. Measure the rendered labels too: text overlapping text, text off the canvas, text under a solid shape. Treat any of these as a failed round.
    • Used in sketch.
