    free LLM tiers are small

    A free model key can't power a loop that runs every few minutes. Measure the quota first, and design for it.

    • Measured 2026-10-20: a free Gemini key gets 20 requests per model per day on gemini-3.6-flash. The quota is per model, and the 429 error says which quota (per day or per minute) and when it comes back.
    • Don't retry a daily-limit 429. Retrying only burns time. Move to the next model on the list, and remember until when each one is used up.
    • Batch work (40 items per call), cache every answer, and call at most hourly on a free key. Paid keys can run every cycle.
    • For a product: a free key means hourly updates, and live updates need a paid key. Say this to users plainly.

    Related: rank-by-evidence-not-hype.
