    wiki 10

    Every wiki page, one line each: [[page]] — one-sentence summary. Agents keep this current. Read this before searching.

    working-with-claude — Scope before code, give every session a finish line, keep the context clean, run independent work in parallel, and keep local settings out of git. test-voice-with-synthetic-speech — Run real audio from macOS say through the real model and parser; catches clipped first words and mishearings. skills-cheatsheet — Every installed Claude Code skill in one line: what it does for you and when to type it. rank-the-unexpected-separately — Popularity-only ranking repeats the crowd's blind spots; give the surprising and the ignored their own lanes. finetune-on-mlx — LoRA on Qwen3.5 with MLX on a 24 GB Mac: batch 4 + grad checkpointing, lr 5e-5, thinking off at serve time, freeze the test set first. test-pictures-with-a-blind-quiz — Quiz a second model on the rendered picture alone, grade against the source, redraw on misses, keep the best round. rank-by-evidence-not-hype — Rank by what you can use today and what is proven; facts found beat model guesses; the reader's ratings are the ground truth. free-llm-tiers-are-small — Free Gemini is ~20 requests per model per day: never retry a daily 429, hop models, batch, cache, call hourly. host-a-site-from-a-private-repo — Free GitHub Pages can't serve a private repo; publish only built files, to Cloudflare or to a second public repo's Pages, never a folder holding .git.
