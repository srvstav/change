    claude / skills / idea · updated 2026-10-13

    SKILL

    Turn the rough idea into ideas/<short-name>.md using templates/idea.md.

    1. Read now.md and grep ideas/, projects/, archive/ and wiki/ for anything related. If it overlaps an existing idea, extend that one instead of making a new file.
    2. Write the announcement first. If it can't be made exciting in one paragraph, say so plainly.
    3. Fill every section yourself from what you know. Then ask the user at most 3 pointed questions — only where the answer would change the pitch. Hardest question first.
    4. Make Done when checkable by a stranger. Make Riskiest assumption come with a test that takes hours, not weeks.
    5. Name it in 1–3 plain words, lowercase, hyphens.
    6. End with one line: your honest read — build now, park, or kill — and why.
