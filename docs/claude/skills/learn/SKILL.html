    claude / skills / learn · updated 2026-10-13

    SKILL

    1. Save. Create sources/YYYY-MM-DD-<short-name>.md from templates/source.md. Put the original text in (or the parts that matter, if huge). Ask the user one line: why is this worth saving? Put it in why:. Binary files (pdf, images) go in sources/files/ and get linked from the note.
    2. Read wiki/index.md. Find every page this source touches.
    3. Fold in. Update those pages with what's new — cite the source with [[YYYY-MM-DD-<short-name>]] and add it to the page's sources:. Create new pages only for ideas that stand on their own. One idea per page.
    4. Connect. Add [[links]] between pages that now relate. Update wiki/index.md.
    5. Flag if the source contradicts something already in the wiki. Don't silently overwrite — note both sides on the page.
    6. If it bears on an active project, say which and how in one line.

    Reply with: pages created, pages updated, contradictions found.
