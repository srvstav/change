    clible-site

    The clible.com site should feel like an experience you watch, not a page you scroll: one living particle field that speaks, changes shape, and tours itself.

    #Resume here (2026-10-21)

    Where it stands: branch spatial in ~/code/clible, commit b2df1cf, local only. User's verdict: "okay enough to keep, not good enough to push". The live site (master) is unchanged.

    What the site is now (master's experience with a few new pieces):

    1. Intro: particles spell "all around you," → "you speak." → "it moves." → "nothing leaves this room." → CLIBLE.
    2. Hero: "You speak. It moves." over the orange particle sphere.
    3. 02 Atlas (new): a room of 112 real engineering photos (from leafers.in).
      • The title holds about 2.5 s, then leaves "ENGINEERING EXPLORER".
      • The room flashes one photo ("open it" brings it back).
      • Drag the room, click to hold a photo, P for particles, index view.
      • The SAY bar takes typed or spoken places: "rockets", "Webb's mirror", "bigger", "surprise me".
    4. Manifesto, Say demo, proof + Razorpay checkout, lab, end: as on master.
    5. Autopilot: one quiet hint per section when idle. The full tour plays only from TOUR.

    Run: npm run dev → localhost:5173. Test: npm run build && npm test (the test doesn't build first; it failed once in 4 runs).

    Not good enough yet, likely gaps (user didn't pick one):

    • whether the first 5 seconds hook people
    • how the room feels (loading, the flash)
    • whether visitors get why Say matters
    • overall polish

    Untested on a real GPU or phone; no Lighthouse run (two WebGL canvases now).

    Lessons:

    • The user wants a blend of them driving and autopilot, never "pure video".
    • Show one element, not five.
    • Keep master's UX and add new things sparingly.
    • Check animations as a frame sequence of a real scroll, not single screenshots.

    Also on disk: branch redesign-v2 (studio redesign, unreviewed); scripts/atlas.mjs re-extracts the photos.

    #The idea (in my words)

    • An awe-inspiring site in the spirit of Awwwards winners. Grounded sci-futurism, not plain sci-fi.
    • On open, dense moving particles change colour and font to spell sentences, like Dolby's "all around you". While they do, the site loads its shaders and fonts in the background.
    • Every movement, click and moment is connected. It should feel alive, dynamic and thrilling.
    • If you don't touch it for 3–5 s, it scrolls itself beautifully. Any real input hands control back at once.
    • Inspiration: aaronjcunningham.com (the dots working together to form things), landonorris.com (OFF+BRAND), Active Theory, twks.ch (and its 404), Michael Gatt, dark.netflix.io, orano.group/experience/innovation, masardestination.com.sa/ar/experience, artisansdidees.com.
    • Tools to borrow from: three.js/WebGL, anime.js, React Bits, Unicorn Studio.

    #What we built (v1, 2026-10-13)

    Stack: Vite + TypeScript + three.js (custom shaders) + GSAP/ScrollTrigger + Lenis. No framework.

    • Intro: 90k particles (32k on mobile) spell "all around you," → "you speak." → "it moves." → "nothing leaves this room." → "CLIBLE", each in a different font and colour. Skip with the button, Enter or Esc.
    • One field, six worlds: the same particles re-form for each section: sphere → dust → voice wave → grid → ring → "say it.". They push away from the cursor and glow orange.
    • Autopilot: after 4 s idle the site tours itself and steps through the Say demo. Wheel, touch, key or click hands control back instantly. Toggle in the bottom HUD.
    • Say demo: a pinned section scrubbed by scroll. The transcript types in, a glowing cursor glides to a tile, a ripple shows the click, and the URL changes.
    • Details:
      • split-text reveals, and manifesto words that light up as you scroll
      • stat counters, and a marquee that reacts to scroll speed
      • custom cursor, magnetic buttons, product rows with hover reveals
      • film grain, and HUD corners with a clock, FPS and chapter label
      • opt-in synthesised sound
    • 404: particles spell "404". Moving scatters them; clicking rebuilds.
    • Design: graphite black, bone white, one signal-orange accent. Fonts: Archivo (variable width) + Instrument Serif italic + JetBrains Mono.
    • Tested: npm test (Playwright) checks the intro, that autopilot starts and hands back control, every section, mobile without sideways scroll, and the 404. It passes.

    #v1.1 (2026-10-14): faster, and the autopilot became Say

    • Autopilot is Say driving the site. A glowing ghost cursor "hears" a command (shown in a voice pill: "show me say", "prove it", "take me home"), glides to the nav link, clicks it, and the page flies there. Each chapter then performs: the manifesto is read, Say runs two live commands, every lab row is hovered, "hello, clible" is typed at the end. Any real input kills it at once.
    • Scroll speed bends the field. Fast travel spreads the particles into vertical streaks (hyperspace feel).
    • Intro fonts: "you speak." is now Syne ExtraBold; "CLIBLE" is Unbounded Black with wide tracking.
    • Say demo no longer pins or scrubs. It loops on its own, about 2.3 s per command, across four commands. It has a live level meter, a latency counter, a curved cursor path and a click flash, and the particle wave shivers while the "voice" speaks.
    • A different trick per section: letters in the hero and manifesto swell near the cursor (variable font), labels decode like a cipher, proof cards follow the cursor with a spotlight, lab rows make the particles spell the product name, and at the end you type and the particles say it back.

    #v1.2 (2026-10-14): the director's cut, real 3D, less jitter

    • Autopilot is now a short film (~35 s loop). Letterbox bars, a running timecode and scene slates ("SC.03 — SAY · TAKE 02") appear. Scenes, in order:
      • an establishing orbit plus a dolly zoom on the sphere
      • the manifesto read line by line
      • a low camera crane over the sound landscape
      • every proof card tilted under the ghost
      • a full orbit of the galaxy
      • a push into the typed words
      • a rewind home, with the timecode running backwards, and a Vertigo shot
    • Real 3D camera. Each world has its own pose: the voice wave became a sound landscape seen from above ("Unknown Pleasures" rows), and the ring became a tilted spiral galaxy. The mouse gives parallax everywhere, and the mouse push is ray-cast so it stays under the cursor at any angle.
    • The ghost is a real pointer. The same code drives the real cursor and the ghost.
    • The page is a 3D sheet that bends with scroll speed. Lab rows flip up like split-flap tiles.
    • CLIBLE is in Monoton. Parallel grooves read like a sound wave. On phones it's split over two lines (CLI / BLE). Picked from 9 fonts rendered in the real field: Monoton > Big Shoulders Stencil > the rest.
    • Jitter fixes:
      • Shapes are built once, in idle time.
      • Interrupted morphs no longer snap.
      • World changes wait for fast scrolls to settle.
      • The cursor effect no longer causes layout or a feedback loop.
      • The background blurs are gone.
      • The warp sprite growth is capped.
      • The pixel ratio drops on slow GPUs.
      • The mobile toolbar resize no longer triggers a rebuild.
    • Smoke test is no longer flaky (an orphan vite server was holding the port).
    • Still open: a one-time ~0.5–0.8 s stall when the autopilot first starts, seen only in software rendering. Check on a real GPU.

    #Perf pass on master (2026-10-20, commit 0533d69, live)

    No visual change. Cloudflare speed test was 47 (TTI 7.9 s, TBT 916 ms): software-GL WebGL work blocked the main thread.

    • three.js renders in a Web Worker (OffscreenCanvas). gl/remote.ts is the main-thread handle, gl/host.ts the renderer; on-thread fallback if no OffscreenCanvas WebGL2.
    • Same Google Fonts files, self-hosted in /fonts (immutable cache), intro faces preloaded. CSS inlined by a Vite plugin → nothing render-blocking.
    • Local Lighthouse, live site (software GL, 6× CPU): desktop 99, mobile 100.
    • Port to redesign-v2 still to do: its field.ts adds uVoice and a drift layer, so those must go through remote.ts → host.ts too.

    #Get Say on master (2026-10-20, commit ce10370, live)

    The proof section ("[ 04 ] Numbers, not adjectives") is now where you buy Say. The 4 stat cards ("$5 once, forever") are gone.

    • The race: by hand vs with Say, ported from v2.
    • Get Say panel (#get): email → Razorpay Checkout through pay.clible.com → a "Say is yours" pass (days left, expiry, key, copy, renew, restore by payment ID).
    • src/get.ts is lazy-loaded (near the panel, on focus, or if a pass is saved), so first paint doesn't pay for it. The pass is re-checked with /api/verify on every visit.
    • ₹ is drawn in the system font. In JetBrains Mono it pulled a 15 kB font file and cost 0.2 s LCP.
    • Lighthouse mobile 97/100/100/100, desktop 100s.
    • Not in v2 or spatial yet. v2's own buy form (end section) sits in git stash on redesign-v2.

    #v3.1 (2026-10-21): master's experience, with the atlas blended in

    Verdict (user, 2026-10-21): "just okay enough to keep but cannot push (not good enough)". Committed locally as b2df1cf on spatial. Not pushed, not merged, not deployed. The next step is to find out what would make it push-worthy. The user asked to keep the live site's UX and blend in only a few v3 pieces.

    • Back from master: the intro ("all around you," → … → CLIBLE), the hero ("You speak. It moves." + the sphere), the manifesto and its dust world, and the orange accent.
    • Kept from v3: the dome, but as its own chapter "02 — ATLAS" after the hero. The section is 190vh with a sticky inside. The room flies in from behind and holds still for about 90vh. Then it flies out forward, fast, so the manifesto gets a clear page. Also kept: hold a photo, particles, index view, and the SAY command bar (only shown in the atlas).
    • Kept from v3: the user drives. Idle gives one hint per section (the hero's ghost brushes the title; the atlas's ghost types "show me rockets"). The tour runs only from TOUR in the bottom bar.
    • Dropped: the "look closer" photo intro, the LHC-tunnel world, the hero tour button, and the hero's duplicate nav.
    • Arrival (2026-10-21): each time you land in the room, the title card shows for about 3 s, then blurs away. A small "ENGINEERING EXPLORER · 112 machines · 10⁻⁹ → 10²⁶ m" label stays. Next the room flashes one striking photo at you (a curated list of 12) for about 2 s and puts it back. That's the "wait, what was that?" hook: click it, or say "open it". Any click, wheel or key cancels the flash, and the tour skips it. The first idle hint in the room types "show me rockets"; every later idle spell flashes another photo.
    • Fixes (2026-10-21), after the user said the room "doesn't load perfectly, one same thing is coming twice":
      • The title used to scroll in, vanish and rise a second time. It now enters once, with the page.
      • The sticky hold never worked: body { overflow-x: hidden } made body a scroll container. It's now clip.
      • The photos now start drifting in as the section enters.
      • Hover captions are off while the title shows.
      • The idle clock restarts after a flash, so a hint doesn't follow right after it.
      • The "full tour" note shows under the bar instead of over the room.
      • npm test failed once in four runs; the cause wasn't found (probably a flash racing the test's clicks).
    • Chapters are now 7. npm test builds nothing: run npm run build first, or it tests a stale dist.

    #v3 (2026-10-21): the atlas dome

    Branch spatial in ~/code/clible, cut from master (live, with the checkout). Not committed, not deployed. Run: npm run dev → localhost:5173. npm test passes.

    • First screen is a dome of real photos, in the style of michaelgatt.com: you stand inside a curved shell of all 112 Tera-Marvel Atlas photos (leafers.in). They're ordered by scale as you turn: chips in front, telescopes behind. Drag it (with inertia), hover a photo for its scale and name, click to fly it in front of you with credit and licence, then ← → through scale. Particles burns the photo away and the particle field rebuilds it in the same spot. Index view turns the dome into a curved wall sorted by scale, with band labels. Scrolling flies you forward through the shell.
    • Intro is now "look closer." → an i9 die, the first Raptor firing and Webb's deep field, each rebuilt in particles with its scale (10⁻⁹, 10¹, 10²⁶ m) → CLIBLE. The manifesto's world is the LHC tunnel in particles.
    • Copy: "Built with small tools." The manifesto ties the atlas to clible: small tools that do one job well.
    • You drive; the autopilot assists (changed after the user said v3 "feels like pure video"):
      • Any click, scroll or key skips the intro.
      • After 7 s with no input at all, you get one quiet hint for the section you're in. Each section hints once. The hint never scrolls or opens anything, and the mouse ends it.
      • The full tour (it turns the dome, holds a photo, burns it into particles, flies on) runs only from the hero's "take the tour" button or the TOUR control in the bottom bar. A deliberate mouse move hands control back with "all yours".
    • Command bar (after the user called the tour-only version "awfully useless"). A fixed "SAY ▸" bar where you type or speak where to go, and the atlas goes there. It's Say's idea working on the site. Examples: "rockets" turns to that band; "Webb's mirror" flies the photo forward; "particles", "next", "bigger"/"smaller" (by scale), "index", "surprise me", "close", and "10^26". Press / to focus it. The try-chips change with what you're doing, and the idle hint types an example into the bar. Parsing is local (src/ask.ts); the mic uses the browser's speech recognition, which in Chrome sends audio to Google. Dome.face(i) turns the short way to a photo.
    • Code:
      • src/dome.ts (three.js on the main thread, loaded after first paint)
      • src/atlas.ts + src/atlas.json
      • public/atlas/ (6.8 MB AVIF, lazy)
      • scripts/atlas.mjs (re-extract from ~/code/tera-marvel)
      • photo() and stars() in shapes.ts
    • Borrowed from: React Bits DomeGallery (sphere placement, drag inertia), CircularGallery (speed bend).
    • Gotcha: in the Atlas build, data-i is display order, not data.json order. Match photos by title.
    • Licences: every photo shows its author, licence and Commons link when held. A credits line sits in the footer.
    • Open: test on a real GPU and phone; run a Lighthouse pass (two WebGL contexts now); decide whether to merge to master and deploy.

    #v2 (2026-10-17): studio redesign

    Branch redesign-v2 in ~/code/clible (commit d5cf5a4, not pushed, not deployed). Run: npm run dev → localhost:5173. Test: npm test (46 checks, ~8 min; npm test -- race runs one).

    • clible = the studio, Say = product 01. Intro: "small tools" → "that do / the thing," → "then leave / you alone." → CLIBLE. Hero: "Tools that leave you alone." End: "Say hello."
    • New: the race (12 hand clicks vs one sentence), "Talk to it" mic (loudness only, nothing sent), per-chapter light, drifting 01–06 numerals, Say pins with a 3D crane.
    • Fonts: Archivo + Fraunces (soft/wonky italic) + JetBrains Mono; Syne/Monoton in intro only.
    • Open: 45/46 pass. Failing: "nav … logo did not go home" (clicking the logo after #end doesn't reach scrollY 0 — check the pin-spacer/lenis scrollTo('#top') path). User hasn't reviewed v2 yet.
    • Not done: add hush/radar to the lab list? (ask first).

    #What we can do next

    1. Make the repo public, then deploy (Vercel or Cloudflare Pages) and point clible.com at it.
    2. Speed: measure FPS on a real graphics card, and drop the particle count on slow devices.
    3. Move the particles to GPGPU (simulated on the graphics card, see the Codrops tutorial) for real flow and physics.
    4. Real mic mode: the voice wave reacts to your voice, through the browser's audio API with the user's permission.
    5. Page transitions to clible.com/say and /roomy (twks-style) with the particles carrying across.
    6. A Unicorn Studio scene for one section, once a project ID exists in their editor.
    7. React Bits / anime.js pieces where GSAP falls short (text scramble, Hyperspeed-style background).
    8. Add real install and pricing links when Say ships.
    9. Add a loader sound and a hover-distortion effect on images (artisansdidees style).
