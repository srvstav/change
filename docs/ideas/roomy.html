    roomy

    Parked 2026-10-13: concern that users won't grant disk access just to save space.

    #The announcement

    "Your disk is full again. You know why: dozens of old node_modules folders, Xcode build files, Docker images, Gradle and pip caches, Rust target folders. Roomy finds every one on Mac, Windows and Linux in seconds and shows exactly how much space each project is wasting. One click frees it, safely: it only removes things your tools can rebuild, and everything goes to the Trash first. Most developers get back 20–80 GB the first time. The scan is free. Cleaning is $5, once, forever."

    #Problem

    Developers' disks fill up with things their tools can rebuild: dependency folders, build outputs, package caches, simulators and container images. They're spread across dozens of folders and ecosystems.

    • Today people cope with du, rm -rf, half-remembered commands per tool, or one-ecosystem tools (npkill for node_modules, DevCleaner for Xcode). Nobody does it until the "disk almost full" warning, usually mid-build.
    • It's worse on 256/512 GB laptops and on Windows, where WSL, NuGet and Gradle quietly grow.

    #Insight

    • Show the value before asking for money. The free scan says "you can recover 47.3 GB". Paying $5 to get 47 GB back is an easy yes.
    • Most competitors are Mac-only (Untainted, TidyDisk, DevPowerCleanup). Windows and Linux developers have command-line tools only. Being cross-platform is the opening.
    • Trust is the product. The tool deletes files, so the brand is "it can never delete your work": rebuildable things only, Trash by default, no symlink following, no crossing drives, and source code is never touched.
    • It won't be wiped out soon. OS vendors don't understand developer caches, and every new tool brings a new cache.

    #Done when

    1. A cold scan of a real dev machine (~1M files) finishes in under 30 s and finds at least 10 GB recoverable.
    2. A test suite on a fixture tree proves zero source files are ever selected (source, .git, .env, recently active projects).
    3. A stranger can go from install → scan → pay (UPI or card) → clean in under 3 minutes on macOS, Windows and Linux.
    4. The licence keeps working offline and when the server is down.

    #Time box

    2 weeks to v1. If it runs over, cut ecosystems, not safety.

    #Riskiest assumption

    Developers will pay $5 instead of using free CLIs or free Mac apps. Test (1–2 days): a landing page on clible.com with a free downloadable scan report and a "Buy $5" button, posted to r/webdev, r/androiddev, r/iOSProgramming and HN Show. Kill if fewer than ~2% of visitors click Buy.

    #Not doing

    • General system cleaning (browser caches, "RAM boosters"): different trust model, different crowd.
    • Subscriptions, accounts with passwords, telemetry beyond crash reports (opt-in).
    • Mac App Store (its sandbox blocks this kind of app); downloading directly from the site is the channel.

    #Design sketch

    desktop app (Tauri 2: Rust core + web UI, ~10 MB)
  scanner   Rust, parallel directory walk; rules per ecosystem (node, python, rust, java/gradle,
            apple/xcode, android, docker, go, .net, homebrew, package caches)
  cleaner   move to Trash (default) or delete; dry run; per-item and per-project
  licence   Ed25519-signed token stored locally, verified offline
backend (FastAPI)
  POST /auth/otp/start  → email a 6-digit code (Gmail SMTP)
  POST /auth/otp/verify → session
  POST /checkout        → payment link (UPI + card)
  POST /webhook/pay     → verify signature → issue licence (idempotent)
  GET  /licence         → re-download a signed licence on a new machine
  storage: SQLite/D1 (users, otp attempts, purchases, licences)
site: clible.com/roomy (download + pricing)

    #Open questions

    • "Only Gmail": does it mean OTP codes are sent from a Gmail account (any user email works), or that only Gmail users can sign in? The second would turn away paying customers.
    • Payments: Dodo Payments (handles global tax for you, UPI + cards, ~4% + fixed fee — check the live pricing page) or Razorpay (UPI + cards; international cards need approval; GST is on you).
    • Code signing: macOS Developer ID ($99/yr) avoids Gatekeeper blocking the app; Windows signing avoids SmartScreen warnings.

    #Runner-up

    • shrink: drop in a video and get it under 10/25 MB at the best possible quality (for GitHub PRs, Discord, email, WhatsApp). Local ffmpeg, so nothing is uploaded. Broader audience; weaker "value before paying" moment.
