    pay

    #The announcement

    Any clible product can be paid for: pay a small amount with Razorpay, get a key, use the product for 30 days.

    #Done when

    A stranger pays with live Razorpay keys at pay.clible.com/buy/?product=say, gets a key, and Say accepts it.

    #Simplest version

    One Cloudflare Worker + D1. Checkout → claim (the server asks Razorpay whether it was paid) → key → verify. No webhook, no signatures, no subscriptions.

    #Not doing

    Auto-renewing subscriptions, user accounts, webhooks, refund revocation.
