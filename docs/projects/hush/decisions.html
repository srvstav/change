    projects / hush · updated 2026-10-21

    decisions

    #2026-10-14 — Name: hush (replaces psst)

    User asked for a different name. "hush" is a real word, one syllable, same meaning, easier to say than psst.

    #2026-10-14 — Name: psst

    One syllable, says "secret" without explaining. Tagline: "Talk like nobody's listening. Because nobody is."

    #2026-10-14 — P-256, not X25519

    WebCrypto P-256 ECDH works everywhere (browsers, Node) without feature checks. X25519 is nicer but support is still uneven.

    #2026-10-14 — Relay logic with no I/O

    hub.js is pure, so GitHub Pages can run the same relay in a SharedWorker. The static demo needs no server.

    #2026-10-14 — Pairwise ratchets, client fan-out

    Group messages are encrypted once per peer (like Signal). Simpler and stronger than a shared group key; costs more upload in big rooms (capped at 16 per room).

    #2026-10-14 — Files: one key per file, encrypted once

    The file key travels through each ratchet; chunks are bound to file id, index, and total count. Acks every 4 chunks, window of 16 (4 MiB) per recipient.
