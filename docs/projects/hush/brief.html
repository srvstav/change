    projects / hush · updated 2026-10-21

    hush

    #Problem

    Mainstream messengers trust their own servers with metadata, accounts, and often keys. None of them make the conversation itself feel different.

    #Insight

    Treat the relay as the enemy. A room is just a passphrase; the relay sees a room id it can't reverse. Everything else (names, words, files) is end-to-end encrypted. The quirky features (riddles, capsules, whispers) are made of real crypto, not just UI.

    #Done when

    • Two strangers on different networks can talk through a public relay and compare safety words.
    • A multi-GB file streams between them without either side holding it in memory.
    • The GitHub Pages demo works with zero servers (tabs via SharedWorker).

    #How we measure

    npm test (24 tests incl. a real relay with 3 clients, 48 MiB × 2 file transfer at ~190 MiB/s locally).

    #Not doing (yet)

    Accounts, history, persistent identity, header encryption, voice.

    #Design

    Engine in src/core (browser + Node). Relay hub has no I/O: wrapped by ws in Node, by a SharedWorker in the browser. See the code repo's README.
