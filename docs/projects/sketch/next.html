    sketch — next

    Where to pick up. Short summary of where things stand on 2026-10-21.

    #Where it is

    • Live: https://srvstav.github.io/sketch/ · code ~/code/sketch · last commit 57c33a3
    • Five shapes (machine, cycle, journey, dominoes, building) and the overview are drawn by code from the model's words. The other 11 shapes are still drawn by the model.
    • Each step has an icon and a number badge. Practice modes: Recall (fill in hidden labels), Explain (say it back), and spaced review on 1/3/7/16/35 days.
    • Checks before a picture is shown: a blind quiz on the picture alone, the layout, cut words, quiz answers written into the picture, and step labels that are made up.
    • Best real run: Gemini 3.8 Flash, 4 ideas, 18 calls, 91 s, mean 95%.

    #Next, in order

    1. Real run on a fresh Gemini quota. Watch how often the made-up-label check costs an extra call.
    2. Same deck with --freeform on Flash-Lite for a clean before/after.
    3. Replace the in-app "Open example" (old hand-drawn deck) with a fresh code-drawn one if it looks as good.
    4. The recall test with 4–8 students: do code-drawn pictures blur together? Does Explain beat Recall?
    5. Maybe move more shapes into code (seesaw, map, anatomy).

    #Watch out

    • The free Gemini quota runs out fast and is shared with radar's key.
    • A Gemini key was once pasted into chat (noted in the notebook log). Rotate it.
