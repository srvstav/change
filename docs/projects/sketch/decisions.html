    decisions

    Newest on top. Never edit an old one — write a new one that replaces it.

    #2026-10-21 — step labels must come from the material

    Why: labels are what students recall and type in. A made-up name ("Carbon Stripping") is something the exam never asks for. Instead of: trusting the prompt alone. A word-match check is cheap and catches it every time; the fix costs one small redraw call. Revisit if: it flags real terms often (short notes, synonyms), or it pushes decks over the free daily quota.

    #2026-10-21 — five shapes are drawn by code from the model's words

    Why: writing a full SVG is the hardest job in the loop, and free models did it badly (overlaps, plain circles). Choosing the shape and the words is the thinking; the layout is craft code does reliably. It also halves the calls per deck (map fills the words, so round 1 needs no draw call; the overview costs none), which is what lets a free key finish a deck. Instead of: the model writing every SVG (still used for the other 11 shapes, and via --freeform). Updates "pictures are SVG, cleaned with an allowlist": they still are, and still go through the cleaner. Revisit if: the recall test shows template pictures blur together, or a strong model's freeform pictures score clearly higher on the same material.

    #2026-10-20 — renamed etch → sketch

    Why: the user's choice. Instead of: etch. Revisit if: the name is taken somewhere that matters.

    #2026-10-20 — support Gemini, Anthropic and OpenAI keys; detect the provider from the key

    Why: students need a free option; Gemini's free tier is the most generous found. One key box, no provider picker. Instead of: Claude only. Revisit if: a provider changes its key format, or free Gemini quotas are too small for a full deck.

    #2026-10-20 — don't bundle Sans Forgetica

    Why: the font file says "Copyright (c) 2018 Letterbox. All rights reserved"; only a distro listing claims CC BY-NC. A public repo would redistribute it. Also, a replication with 882 people found no memory benefit. Instead of: shipping the .otf. Revisit if: RMIT's licence text clearly allows web embedding.

    #2026-10-20 — UI copy is functional only: no taglines, claims or praise

    Why: the user's rule: every word on screen must help the student do something. Only the product name is exempt. Instead of: a marketing hero ("Read it once. See it in the exam.") and boastful helper text. Revisit if: never without the user asking. Applies to every new screen, button, toast and export.

    #2026-10-20 — judge sees only the rendered PNG; grader sees the source

    Why: the point is to test whether the picture alone carries the idea. Judging SVG text would leak labels that are unreadable in the real picture. Instead of: one call that looks at the picture and the source together (it would grade itself generously). Revisit if: the judge is too strict on pictures students find clear, judging by the human recall test.

    #2026-10-20 — browser-only, bring your own key, no backend

    Why: fastest path to a working v1 and to the recall test; notes and keys never touch our servers. Instead of: a hosted backend with our key. Revisit if: students won't make a key (expected). Then add a small proxy with a free weekly allowance.

    #2026-10-20 — default to Claude Opus 5.5, user can switch to Sonnet/Haiku

    Why: picture quality is the whole bet; test the best model first, then see what cheaper ones lose. Instead of: starting cheap. Revisit if: the CLI scores show Sonnet 5.5 matches Opus on picture-only scores at lower cost.

    #2026-10-20 — pictures are SVG, cleaned with an allowlist and shown only via

    Why: SVG lets etch hide labels for recall and export crisp files; <img> never runs scripts, so a hostile PDF can't inject code. Instead of: model-written HTML in an iframe. Revisit if: a needed visual can't be drawn in plain SVG.
