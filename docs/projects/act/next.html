    • Local AI: Ollama qwen3:8b (always on). Don't pin it while training.

    1. Resume training only when the Mac is idle (it fills the GPU and memory): cd ~/code/act && uv run mlx_lm.lora -c train/l1_lora.yaml --model Qwen/Qwen3.5-0.8B --adapter-path adapters/l1-0.8b --resume-adapter-file adapters/l1-0.8b/0000400_adapters.safetensors > results/train-l1-0.8b.log 2>&1
    2. Serve and score it: train/ship.sh 0.8b, then uv run python eval/run_l1.py --url http://127.0.0.1:8081/v1 --model default_model --style student --name act-0.8b
    3. If it beats qwen3:8b (74.1%, 5 unsafe): set SAY_AI_PROMPT=act, SAY_AI_BASE_URL=http://127.0.0.1:8081/v1, SAY_AI_MODEL=default_model in ~/code/say/server/.env.
    4. Speech mishears ("tube"→"tool", "lofi"→"low phi"): add sounds-like fixes in extension/src/parser.ts; add real Whisper slips to act's training data.
    5. Add your own phrases in act lab (the honest test).
