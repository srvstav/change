    #2026-10-21 — host on Cloudflare Workers + Durable Objects

    Why: duet needs a server that keeps WebSockets open; GitHub Pages only serves static files. Wrangler was already logged in. Free, always on, no cold starts, and hibernation makes empty rooms cost nothing. Instead of: Render (free tier sleeps), Fly (needs a card), GitHub Pages (no server). Revisit if: the workers.dev address (it contains the email name) matters: add a custom domain.

    #2026-10-21 — real recordings, a sampled arrangement for one

    Why: synthesized scores sounded like a toy. Wikimedia Commons had free recordings for four pieces: Ishizaka (CC0), Kevin MacLeod (CC BY), Goedhart (public domain), the Air Force Strings (public domain). Instead of: fetching copyrighted LP rips from archive.org. Revisit if: a free Nutcracker Pas de deux recording turns up; Musopen is the place to check.

    #2026-10-21 — closeness as the core mechanic

    Why: the user asked that the pieces "work together, not as disconnected elements". One number, how close you are, now drives the music filter, the colour grade, the thread and the bloom, so everything answers the same thing. Instead of: more features side by side.
