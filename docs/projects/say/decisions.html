    decisions

    Newest on top. Never edit an old one — write a new one that replaces it.

    #2026-10-21 — Wake phrase: opt-in, checked on the device, false alarms stay silent

    Why: User wants "hey, open YouTube" with no key. Reuses the speech model already running (no new model). The mic stays open only while the setting is on. Each utterance becomes text in the offscreen page; anything not starting with the wake phrase is dropped there, never stored or sent. A wake session that isn't a command hides quietly and never goes to the AI fallback. Turning it on also asks for every site, because without a key press the browser gives no activeTab. Instead of: A dedicated wake-word model (Porcupine needs a key; openWakeWord has no "hey"). Revisit if: CPU use from always transcribing is a problem, or false wakes from conversation annoy people.

    #2026-10-21 — Sky blue again (replaces "Orange is back")

    Why: User asked for sky blue everywhere: cursor, icon, overlay. Same shade-for-shade mapping as the first time; icons recoloured again. Kept: error colours.

    #2026-10-21 — Orange is back (replaces "sky blue" below)

    Why: User: "I loved the previous one, I want it back." Every value mapped back to its exact original orange shade per file; icons restored from git; --sky tokens are --ember again. Instead of: Sky blue. Revisit if: The user asks again; the mapping is in the entry below.

    #2026-10-21 — Tests never build into dist/

    Why: The browser loads dist/ live. Test and bench builds written there broke the user's Say mid-session ("sometimes it doesn't work"). Now --e2e builds go to dist-e2e/, bench model/device overrides are refused outside --e2e, and the real build writes to dist.tmp then swaps in one rename, so dist/ is never half-written. Instead of: One shared dist/. Revisit if: Never.

    #2026-10-21 — Brand colour: sky blue, not orange, across the platform

    Why: User's call: "wherever orange is used, change it to sky blue". Shade for shade on the Tailwind sky scale: main #ff5a1f → #0ea5e9, soft #ff8a4c → #38bdf8, deep #c2360b → #0369a1, cream-page accent #e8501c → #0284c7 (white button text stays readable). Tokens renamed --ember* → --sky*. Applies to say (extension, icons, server pages, agent lab), act lab, pay, clible. Instead of: Keeping orange. Kept: error colours (#b4543b, #e08a72, #f0a28c). If errors were blue they would look like the brand and stop reading as errors.

    #2026-10-21 — Optional "tabGroups" permission, for "organize my tabs"

    Why: User needs tab organizing daily. Naming and colouring groups needs tabGroups; site names come from tab URLs, which needs the existing optional tabs. Both are asked together by the existing "Switch and organize tabs by voice" toggle in settings, so install asks for nothing new. E2E builds grant both up front (tests can't click prompts). Instead of: Making them required (an install-time warning for everyone), or grouping without names and colours. Revisit if: Chrome Web Store review objects, or people want organizing without tab switching.

    #2026-10-21 — Default speech: whisper-base.en on the CPU, not Distil-Whisper on WebGPU

    Why: The user's Brave has many tabs (82 processes, 21 GB on a 24 GB Mac) and can't run with fewer. Under that pressure Distil on WebGPU hung for 400 s+ without loading, and when it did load it took 2.3 GB in Say plus ~1.8 GB more in the GPU process. whisper-base.en on CPU (q8, 7 threads): ~650 MB total, first load 4–9 s, 1.27–1.30 s from end of speech to action, 12/12 on the voice check after two sounds-like fixes ("shtab", "chat gpd"). It also heard "take me to the tube" right, where Distil heard "tool". Instead of: Distil on WebGPU (1.0 s, but ~4 GB and unreliable on a busy machine). Whisper-base on WebGPU was 0.94 s but ~2.9 GB. Revisit if: End-of-speech latency must reach < 1 s and cutting the 750 ms end-of-speech wait isn't enough, or real voices do worse than the 12-phrase check.

    #2026-10-13 — Vault tracks agent-skill issues as local markdown in .scratch/

    Why: The vault has no git remote; local files need no setup and stay in the vault. Instead of: GitHub Issues. Revisit if: The vault gets a GitHub remote, or issues belong in ~/code/say instead.

    #2026-10-13 — Rewrote vault history to drop .claude/settings.local.json

    Why: Machine-local settings shouldn't be in git; nothing was pushed yet, so rewriting was safe. Instead of: Just untracking it (the file would stay in the first commit). Revisit if: Never. After a push, untrack only; don't rewrite.

    #2026-10-13 — Gmail-only sign-in; dot/+tag variants collapsed to one account

    Why: User's call. Collapsing variants stops people farming free allowances with ada+1@, a.da@. Instead of: Any email. Revisit if: People without Gmail ask to buy.

    #2026-10-13 — AI fallback = open model behind an OpenAI-compatible endpoint (default Llama 3.3 70B on Workers AI)

    Why: No paid API budget. Workers AI has a free daily allowance and the user already has Cloudflare. The same code works with Groq, OpenRouter or local Ollama. The model can only return one of Say's fixed intents, and the extension re-validates it. Instead of: Claude Opus 5.5 (no key, ongoing cost). Revisit if: Unknown-command rate > 15% or free tier runs out.

    #2026-10-13 — Distil-Whisper small.en is the default speech model

    Why: Near Whisper-small accuracy and several times faster; 12/12 on the synthetic voice test vs base.en tying it. Free, on-device. Instead of: whisper-base.en (kept as "Lighter"), moonshine-tiny ("Tiny"). Revisit if: First download (≈170–260 MB) hurts activation.

    #2026-10-13 — Deterministic command grammar, no AI model in v1

    Why: Simple commands need to be instant (<1 s), free per use, and never wrong. A cloud model would cost more than a $5 lifetime sale. Instead of: Sending every command to a model. Revisit if: More than 15% of real commands go unmatched.

    #2026-10-13 — Speech-to-text runs on the device (transformers.js, WebGPU → WASM fallback)

    Why: Privacy is the product, and there's no server cost per command. Instead of: The Web Speech API (sends audio to Google) or a cloud STT service. Revisit if: First load is too slow or accuracy on Indian English is below 90%.

    #2026-10-13 — Dodo Payments, licence as an Ed25519-signed token verified offline

    Why: UPI + cards, global tax handled; the extension keeps working when the server is down. Instead of: Razorpay (GST on us); online licence checks (single point of failure). Revisit if: Dodo fees or payouts become a problem.

    #2026-10-13 — Backend is a plain container (FastAPI + SQLite), behind Cloudflare DNS

    Why: Gmail SMTP needs real TCP sockets, and Python on Cloudflare Workers runs in Pyodide, where smtplib won't work. A container runs anywhere (Cloudflare Containers, Fly, Railway, a VPS). Instead of: FastAPI on Cloudflare Python Workers. Revisit if: Email moves to an HTTP API.
