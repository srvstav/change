    next — pick up here

    State on 2026-10-21. Read this, then go.

    #You (once)

    1. brave://extensions → reload Say. Open tabs keep working; no page refresh needed.
    2. Say's settings: turn on Switch and organize tabs by voice, add your sites under Your sites, turn on Wake phrase (allow every site when asked).
    3. Try: "hey, open YouTube" · "hey" … "organize my tabs" · "open leafers dot in" · "open Jensen Huang video".

    #What Say does now

    • Hotkey (Option+S) or wake phrase ("hey", changeable), voice model loads when Brave starts.
    • Speech: whisper-base on CPU, ~0.85 GB, ~1.3 s from end of speech to action.
    • Any spoken address opens ("clible dot com"); "Your sites" fixes misheard spellings; " video" → YouTube.
    • "organize my tabs" groups by site (coloured, folded); "ungroup my tabs" undoes.
    • Sky blue overlay with progress ring; visible-pill checked by tests.

    #Rules learned the hard way

    • Never build into extension/dist/ for tests: use node build.mjs --e2e (→ dist-e2e/). The browser loads dist/ live.
    • Check UI in the built extension on a real page, by pixels, not by counting elements.

    #Do next, in order

    1. Speed: cut the 750 ms end-of-speech wait (start speech-to-text after ~300 ms of quiet; act if it's a whole command). Goal < 1 s.
    2. Meaning match (L2 in the plan): small embedding model so odd phrasing works without a big model.
    3. Memory of corrections ("no, I meant…").
    4. act 0.8B as fallback once it beats qwen3:8b; big model as teacher. See projects/act/next.

    #Open

    • Nothing committed in ~/code/say, pay, act. Commit when happy.
    • clible keeps going back to orange (another session edits it). Decide which colour clible should have.
    • Wake phrase keeps the mic on: watch CPU and false wakes.
