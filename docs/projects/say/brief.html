    projects / say · updated 2026-10-13

    say

    #The announcement

    "Press a key, say what you want, and it happens. 'Open YouTube.' 'Play a sad piano song.' 'Next tab.' 'Scroll down.' 'Close this.' Say is a browser extension that does simple things the moment you say them: under a second, no account at a big AI company, and your voice stays on your computer. A glowing cursor shows exactly what it's doing while it moves. Try 50 commands free. $5 unlocks it forever."

    #Problem

    • Some people can't comfortably use a mouse and keyboard: RSI, wrist pain, motor impairments, a broken arm. The current tools are expensive (Dragon) or hard to learn (Talon).
    • Some people's hands are busy: cooking, eating, holding a baby, standing back from the screen.
    • The big AI browsers (Gemini in Chrome, Atlas, Comet, Claude for Chrome) are slow, made for multi-step chores, need their own app or subscription, and send everything to the cloud.

    #Insight

    • Speed matters more than smarts for simple commands. Ninety percent of what people say is about 20 command shapes. A fixed set of commands answers them instantly, costs nothing, and never gets one wrong. A model is only the fallback for fuzzy requests.
    • The voice stays on the device. Speech-to-text runs in the browser through WebGPU (an open Whisper or Moonshine model), so it's private and has no per-use server cost. That's the only way a $5 lifetime price works: a cloud model on every command would cost more than the user paid.
    • The cursor is the trust. You watch it move to the thing and click it. Nothing happens out of sight.

    #Done when

    1. The top 20 commands go from end of speech to action in under 1 s on a 2020 laptop, with no network for speech.
    2. At least 95% of those commands are understood correctly by 10 different voices and accents (Indian, US and UK English to start).
    3. Install → first command works in under 60 s. Pay → unlock in under 2 min (UPI or card).
    4. The permissions screen asks for nothing beyond what the commands need.

    #How we measure

    • Latency: end of speech → action, logged per command in the extension (p50/p95 in the options page).
    • Accuracy: a fixed list of 60 spoken phrases checked through the parser (unit tests) + a manual 10-voice check.
    • Money: visits → installs → first command → paid, from the backend.

    #Simplest version

    Hotkey → mic → on-device speech-to-text → about 20 grammar commands → actions with the glowing cursor, plus email-code login and a $5 unlock. No AI fallback in v1.

    #Time box

    2 weeks to v1 on Chrome/Edge/Brave (all Chromium). Firefox later.

    #Riskiest assumption

    People will actually talk to their browser, and enough of them will pay. Test (2 days): a rough extension with 10 commands, given to 10 people including 3 with wrist/hand pain. Kill or re-aim if fewer than 3 use it again on day 3 without being asked.

    #Not doing

    • Multi-step agent chores (booking, forms, buying). That's where the giants are, and where mistakes cost money.
    • Driving ChatGPT's page to fetch links: its layout changes and breaks the automation. Search the target site directly instead.
    • Typing passwords, payments, or anything on banking pages. Hard-blocked.

    #Design sketch

    extension (Manifest V3, Chromium)
  hotkey (commands API) → offscreen doc records mic → on-device STT (WebGPU)
  text → command grammar (instant) → else small-model fallback (rate-limited)
  actions: open site · search site · click result N · play/pause · scroll · back/forward
           · new/close/switch tab · read title
  cursor overlay: animated pointer glides to the target, ripples on click
  licence: Ed25519-signed token in storage, verified offline; 50 free commands
backend (FastAPI): OTP via Gmail SMTP · checkout · payment webhook → signed licence · restore
site: clible.com (landing, pricing, install link)

    #Open questions

    • On-device STT model choice and size versus first-load time. Benchmark Moonshine vs Whisper tiny/base before committing.
    • Chrome Web Store review of mic + broad host permissions: request host access per site when it's needed, rather than all sites up front.
