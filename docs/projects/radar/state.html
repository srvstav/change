    Last updated 2026-10-20 (evening). Replace this file each session; history lives in log.md.

    #Where things are

    • engine (private): ~/code/radar → github.com/srvstav/radar-engine
    • public home (no code): ~/code/radar-site → github.com/srvstav/radar · demo srvstav.github.io/radar
    • data and cache: ~/.radar/ (radar.db, latest.json, digests/, img/, profile.toml optional)

    #Run

    radar start                                         # once: Keychain key, background at login, opens page
radar stop | radar key | radar eval                 # stop · change key · rating report
uv run radar run | sources | watch                  # one digest | health check | notify-only
uv run pytest -q                                    # 35 tests

    #Code map (radar/)

    sources.py adapters + SOURCES list · engine.py pipeline · rank.py score/surprise · claims.py "first/enables" sentences · today.py Try/Read/Watch picks · media.py images/clips · llm.py one call for Anthropic/OpenAI/Gemini · judge.py usefulness rubric · evaluate.py rating loop (radar eval) · reactions.py HN/Reddit "people made" · store.py SQLite+kv cache · server.py HTTP + /img cache · web/index.html the whole UI (meta radar-mode=live|demo)

    #Refresh the public demo

    uv run radar run → cp ~/.radar/latest.json ~/code/radar-site/data/today.json (trim not required) → commit + push radar-site. If the UI changed: re-export index.html with radar-mode=demo (see the git history of radar-site).

    #Open

    1. Set ANTHROPIC_API_KEY or GEMINI_API_KEY, then uv run radar run. Judge and Today have never made a live call (SDK 1.15 accepts fallbacks; the server's answer is unverified).
    2. v2: rated by usefulness, rating loop, 3 providers, redesign — all pushed. Next: rate 20+ items → radar eval; then Phase 2, the live stream (brief.md "v2").
    3. Set GITHUB_TOKEN (read-only) so traction and repo cards don't hit the 60/h limit.
    4. Upload assets/hero.png as the repo's social preview (Settings, manual step).
    5. Before charging: Reddit and others restrict commercial use. Link out and show thumbnails; don't re-host.
    6. arXiv API was throttled on this IP; the engine skips it when down.
    7. Demo snapshot refreshed by hand (radar-engine README, 'Update the public demo'). Automating it means timed pushes to a public repo; ask first.
    8. Brief's 7-day test (misses vs noise in the top 10) has not started.
