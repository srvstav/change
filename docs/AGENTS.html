    how it works · updated 2026-10-21

    change

    #Map

    now.md        what matters now — read every session
inbox.md      anything, unsorted, newest on top
ideas/        one file per idea not yet started
projects/     one folder per active project
archive/      finished or dropped projects
sources/      raw material collected (papers, posts, repos, talks) — never rewritten
wiki/         what we know — compiled from sources and projects
templates/    starting shapes for new files
docs/agents/  config for mattpocock-skills (issue tracker, labels, domain docs)
.scratch/     local issues and specs for mattpocock-skills

    A project folder holds three files:

    projects/<name>/
  brief.md      why, what, done-when — the spec
  log.md        what happened, newest on top
  decisions.md  what we chose and why, newest on top

    Code does not live here. It lives in its own git repo (default ~/code/<name>), linked from the code: field in brief.md.

    #Flow

    inbox ──► ideas ──► projects ──► archive
                        │
sources ──► wiki ◄──────┘   (every project teaches the wiki something)

    #Rules for agents

    1. Start from now.md, then the relevant brief.md, then wiki/index.md. Grep before guessing.
    2. The vault is memory. Write durable knowledge here, not in tool-private memory.
    3. Never rewrite sources/. Add to it; never edit what's in it.
    4. Logs and decisions are append-only. New entries on top. Fix mistakes with a new entry.
    5. Wiki pages: one idea per page. First line under the title is a one-sentence summary. Every new or renamed page gets a line in wiki/index.md. Link related pages with [[name]].
    6. File names: lowercase, hyphens, no dates in names except in sources/. attention-is-all-you-need.md.
    7. Plain words. No jargon a smart outsider wouldn't know. Short sentences.
    8. Ask before moving a project to archive/, deleting anything, or changing this file. Propose changes to this file as a diff in your reply.
    9. When a good answer comes up in chat, file it into the wiki so it compounds.

    #Rituals

    Each is a skill in .claude/skills/<name>/SKILL.md. Any agent can read and follow them.

    Say What happens
    /idea Shape a rough thought into a sharp pitch in ideas/
    /start Turn an idea into a project with a brief, log, decisions, and a code repo
    /log End of a work session: log it, record decisions, pull lessons into the wiki
    /learn Add a source and fold what it teaches into the wiki
    /reflect Weekly: clear the inbox, refresh now.md, tidy the wiki, sharpen these rules
    /done Close a project: write what we learned, move it to archive/
    continue Resume: check every Focus project, show the top 3 improvements that have evidence behind them, start one on a yes

    #Learned

    Rules from real mistakes. /reflect adds, merges, and prunes. Max 30 lines — the weakest goes first.
